# frontmatter-gen 0.0.17 highlights

## Highlights ⭐️

* **Breaking: traversal is a `..` component, not a substring**: `utils::fs::validate_path_safety` (also behind `Config` directory checks, `create_directory` and `copy_file`) now uses `commons::path::safe_join` from `euxis-commons` 0.0.9. A path is refused only when a `..` climbs above where it starts, so `a..b.md`, `..hidden` and `a/../b` are accepted, while `../x`, `a/../../x` and `/../etc` are still refused.
* **Breaking: backslashes follow the platform**: On Windows `\` is a separator, so ordinary Windows paths are accepted and `..\x` is refused as traversal. Elsewhere `\` is an ordinary file-name character, so `dir\file.md` is one name and accepted.
* **Windows reserved names are complete**: `COM2` to `COM9` and `LPT2` to `LPT9` are now refused, as are reserved names with an extension or trailing spaces (`nul.md`, `CON.txt`).
* **New exact pin `euxis-commons = "=0.0.9"`**: Only its dependency-free `path` feature, pinned under ADR-0005 and checked by the version script. No signature changes and MSRV stays 1.89.0.
