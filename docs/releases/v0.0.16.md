# frontmatter-gen 0.0.16 highlights

## Highlights ⭐️

* **Breaking: front matter must open the document**: A YAML or TOML fence now counts only at the top of the document (after an optional BOM and whitespace) and closes only on a line that is exactly the fence. A `---` that appears only later in a document, inside a value, or as a `----` rule is no longer front matter, and `---\n---\nBody` extracts as empty front matter.
* **Breaking: unterminated fences report `Error::ExtractionError`**: An opening fence with no closing line used to return `Error::InvalidFormat`. Code that matches on the error variant needs updating.
* **JSON body offset and panic fixed**: Leading whitespace before a JSON block no longer leaves part of the JSON in the body, and multi-byte leading whitespace (U+3000, a BOM) no longer panics on a char boundary. The panic input is kept as a fuzz regression.
* **Exact `dtt` pin**: `dtt` is written as `=0.0.11`, as ADR-0005 requires, so the version check now covers it.
