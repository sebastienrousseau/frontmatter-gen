# frontmatter-gen 0.0.12 highlights

## Highlights ⭐️

* **RUSTSEC-2026-0333 cleared**: `noyalib` moves from `=0.0.37` to `=0.0.56`, so `cargo deny` and `cargo audit` stop failing in projects that depend on this crate. Front matter within noyalib's nesting and key-length limits parses to the same values as before.
* **An honest Rust floor**: `rust-version` was 1.85.0, but the dependency graph has needed 1.88.0. The manifest now says 1.88.0, and a new CI job checks the build on exactly that toolchain.
* **Current dependencies**: `clap`, `tera`, `thiserror`, `toml`, `uuid` and the CI actions are at their latest releases, with cargo-vet records to match and two fewer exemptions.
