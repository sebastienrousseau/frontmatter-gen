# frontmatter-gen 0.0.15 highlights

* **100% line and function coverage across both engines**: Every module (`cli`, `config`, `engine`, `error`, `extractor`, `lib`, `main`, `parser`, `ssg`, `types`, and `utils`) now achieves `100.00%` line and function coverage under `cargo-llvm-cov` (`5,595 / 5,595` lines on stable, `5,521 / 5,521` on nightly, `650 / 650` functions) and `cargo-tarpaulin` / Codecov (`1,085 / 1,085` lines, `0` misses).
